# Bugfix Requirements Document

## Introduction

フィード画面のレビューカード（ReviewCard）において、ハッシュタグが4件以上ある場合に「+N」という件数インジケーターが表示される。この表示はユーザーにとって情報価値が低く、実際のハッシュタグをそのまま見せた方が UX が良い。本バグ修正では、省略インジケーターを廃止してすべてのハッシュタグを表示するよう変更する。

## Bug Analysis

### Current Behavior (Defect)

1.1 WHEN レビューカードに4件以上のハッシュタグが設定されている THEN システムは先頭3件のハッシュタグのみを表示し、残りを「+{N-3}」というインジケーターで省略表示する  
1.2 WHEN レビューカードに4件以上のハッシュタグが設定されている THEN システムは4件目以降のハッシュタグテキストを DOM に描画しない

### Expected Behavior (Correct)

2.1 WHEN レビューカードに4件以上のハッシュタグが設定されている THEN システムはすべてのハッシュタグを省略せずに表示する  
2.2 WHEN レビューカードに4件以上のハッシュタグが設定されている THEN システムは「+N件」のようなオーバーフローインジケーターを表示しない

### Unchanged Behavior (Regression Prevention)

3.1 WHEN レビューカードに3件以下のハッシュタグが設定されている THEN システムはすべてのハッシュタグを引き続き表示する  
3.2 WHEN レビューカードにハッシュタグが1件も設定されていない THEN システムはハッシュタグエリアを引き続き表示しない  
3.3 WHEN レビューカードが表示される THEN システムはいいね数・写真・スポット名などのハッシュタグ以外のレビュー情報を引き続き正しく表示する
